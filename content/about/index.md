## A path that started with networks

I started in Computer and Network Engineering at SMKN 1 Raman Utara. That foundation led me toward software: first through independent practice, then Coding Camp 2025, government web projects, and open-source development.

I’m now studying Information Systems at Universitas Terbuka while continuing to build web applications, explore backend systems, and work on projects through LEAP OSS.

## What I like working on

Practical applications where the interface, data, and underlying workflows fit together. I enjoy fullstack web development, backend engineering, developer tooling, and the occasional deep dive into Minecraft plugin mechanics.

I prefer showing specific work over calling myself an expert. The projects on this site reflect that: some are built applications, some are contributions, and some are still taking shape.

## The tools I work with

- **Languages:** JavaScript, TypeScript, PHP, Java, Python, SQL, HTML, and CSS.
- **Frontend:** React, Next.js, Tailwind CSS, Vite, and responsive interfaces.
- **Backend:** Laravel, REST APIs, Express.js, and FastAPI.
- **Data:** MySQL, PostgreSQL, and Prisma.
- **Workflow:** Git, GitHub, Maven, testing, deployment, and collaborative development.
- **Other interests:** Paper/Bukkit plugin development and network troubleshooting.
