## The context

Bapokting presents information about market prices. Behind that public information is an administrative task: keeping the underlying data organized and making updates manageable.

I contributed to the project during my July–October 2025 web development internship at Diskominfo Kota Metro.

## My role and contribution

My work focused on two parts of the application:

- **Administrative CRUD features** for managing market data.
- **Price-chart visualization** for presenting price information visually.

These were contributions within an existing municipal application. The project page describes the components I worked on, while the live site represents the broader platform.

## Maintaining the data

CRUD workflows cover creating, reading, updating, and deleting records. In an application like Bapokting, that administrative side is part of keeping the information shown to users useful over time.

My contribution connected day-to-day data management with the information the application presents. The focus was practical: supporting the people responsible for maintaining market records.

## Presenting price information

Charts provide another way to read the market data beyond individual values. Working on price visualization meant considering how the data should be presented alongside the administrative features that maintain it.

This was an opportunity to work on both data-management interfaces and the visual presentation of information in the same project.

## Public access and project scope

The **Live demo** button opens the public Bapokting application supplied for this portfolio. Internal administrative screens and a public source repository are not included here.

The contribution tags describe the work I can attribute directly: CRUD workflows and data visualization. A module-specific framework stack has not been established for this page.
